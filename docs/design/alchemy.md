# Алхимия: Зелья, Модификаторы, Мутации, ДНК (v1, черновик к тикету 008)

Термины — [CONTEXT.md](../../CONTEXT.md), Ингредиенты и Свойства — [ingredients.md](ingredients.md). Числа стартовые.

## 1. Зелье

- **Котёл** в Норе берёт **3 Ингредиента** (апгрейд Норы — до 5). Зелье = сумма их Свойств с повторами: `{Едкое: 2, Живое: 1}`.
- **Повтор усиливает**: количество одного Свойства в Зелье — его **Ступень** (1–3+). Ступень — главная ручка силы.
- **Доминанта** Зелья — Свойство с наибольшей Ступенью (ничья — по порядку Ингредиентов в Котле; порядок виден и его можно менять).
- Зелье — предмет в Норе: не пропадает, можно копить, лить и пить в любой момент. Одно Зелье — одно применение.
- **Именные Рецепты** (тикет 007 → позже): фиксированные тройки с особым результатом, перебивают общее правило. В v1 — ни одного, ячейка оставлена.

## 2. Вылить на карту → Модификаторы

Перед Вылазкой Стая выливает 0–2 Зелья на карту. **Каждое Свойство Зелья даёт свой Модификатор** со Ступенью = количеству этого Свойства. Модификатор всегда **риск + награда** (PoE): он делает карту опаснее и щедрее одновременно. Ступень 2 удваивает эффект и +25 % к выпадению Ингредиентов с этим Свойством, Ступень 3 — ещё и гарантирует один редкий Ингредиент этого Свойства где-то на карте.

| Свойство | Модификатор | Риск | Награда |
|---|---|---|---|
| Едкое | **Кислотный дождь** | лужи кислоты на асфальте — урон крысам при беге | забор разъеден: открыт дополнительный проход/Выход; Едкие Ингредиенты чаще |
| Гнилое | **Помойный день** | Голубей-воришек ×2 (слетаются на вонь) | Люди брезгуют — реже гонятся; Гнилого больше; Мусор ×1.5 |
| Живое | **Час пик** | Людей ×1.5, Переполох растёт быстрее | Органов пропорционально больше; Выделения падают чаще |
| Сладкое | **Праздник во дворе** | Детей ×2, их крик даёт Переполох ×2 | сладкая Еда рассыпана по карте; Дети уязвимы — Органы и Выделения |
| Жирное | **Масляный гололёд** | асфальт скользкий — инерция крыс выше, остановиться трудно | Люди падают на бегу и роняют всё; Дворник бесполезен |
| Заразное | **Эпидемия** | на 60 % Переполоха приходит **Дезинсектор** (неубиваем, травит облаком) | Заражение передаётся при контакте с высоким шансом, стадии вдвое быстрее — ферма Органов |
| Шумное | **Салют** | Переполох стартует с 30 % | Люди оглушены: не слышат крыс и замечают только вплотную; Петарды и Шумное везде |
| Липкое | **Жвачка везде** | липкие пятна на асфальте — крыса вязнет на секунду | Люди вязнут намертво, Голуби не могут взлететь (их легко бить) |

Два Зелья на одну карту складываются: Свойства суммируются, Ступени растут. Три Модификатора Ступени 3 на одной карте — «дикая карта», к ней Стая идёт за уникальными Органами.

## 3. Выпить → Мутация

Крыса пьёт Зелье в Норе. **Доминанта** Зелья выбирает семейство Мутации, её Ступень — силу. Остальные Свойства Зелья в Мутацию не идут, но сдвигают ДНК (§4).

- Повторное питьё той же доминанты **повышает Ступень** Мутации (1 → 2 → 3), не создаёт вторую.
- Выше Ступени 3 — только **Жирное**: оно складывается бесконечно («мышь жирная» — это буквально). Остальные на Ступени 3 упираются, дальше питьё даёт только сдвиг ДНК.
- Мутаций без лимита, снимать нельзя. Крыса — сумма своих решений.

| Свойство | Мутация | Ступень 1 | Ступень 2 | Ступень 3 |
|---|---|---|---|---|
| Едкое | **Кислотная пасть** | укус ×1.5 урона | ×2, Голубь умирает с одного укуса | ×3, укус прожигает забор — новый проход |
| Гнилое | **Вонючка** | Голуби-воришки облетают тебя | все Голуби облетают | Люди брезгуют: шанс погони −50 %, Переполох от тебя −30 % |
| Живое | **Живучка** | +25 % HP | +50 % HP, регенерация на земле | +100 % HP, встаёшь сама после 30 с лёжа |
| Сладкое | **Сахарная** | скорость +10 % | +20 %, прыжок выше на полтайла | +30 %, Дети бегут к тебе сами |
| Жирное | **Жирная мышь** | +1 ячейка Карманов, −5 % скорости | +2, −10 %, спрайт толще | +3, −15 %, топот наносит вдвое меньше; **дальше без предела**: каждое питьё +1 ячейка, −5 %, ещё толще |
| Заразное | **Чумная** | укус заражает (10 %) | 25 %, Метка без питья раз в 60 с | 50 %, Заражённые Люди считают тебя своей — не паникуют |
| Шумное | **Визгунья** | Действие с земли = визг: паника Людей в 3 тайлах, кулдаун 20 с; визг +2 % Переполоха | радиус 5, +4 % | радиус 8, +6 %, Голуби разлетаются |
| Липкое | **Липучка** | лазание по стенам на 2 тайла | по любым стенам | и по потолку |

Минусы встроены там, где они смешные (Жирная медленнее, Визгунья шумит), а не везде — пользователь не хотел наказаний за мутации.

## 4. ДНК

**Что это как данные:** вектор из 8 чисел по Свойствам, `0..∞`, у новой Крысы сумма ≈ 100: три случайных **доминантных гена** по 20–40, остальные по 3–10. Хранится в аккаунте Крысы, виден в Норе как «анализ».

**На что влияет:**
1. **Сила Мутации** = базовая × `(0.5 + ген/100)`. Ген 50 → ×1.0, ген 0 → ×0.5, ген 100 → ×1.5, ген 200 → ×2.5. Та же Мутация у двух Крыс — разная.
2. **Внешность:** оттенок шерсти — смесь цветов двух старших генов; Жирное — толщина; Липкое — лапы длиннее; Шумное — рот открыт. Крысу видно по ДНК.
3. **Голоса Ингредиентов** (позже): Крыса с высоким Гнилым «чует» Гнилые Ингредиенты сквозь стены.

**Как меняется:** каждое выпитое Зелье прибавляет к гену **+10 за каждое вхождение** Свойства (Зелье `{Едкое: 2, Живое: 1}` → Едкое +20, Живое +10). Убывания нет. Следствие: крыса, которая пьёт одно и то же, становится в этом непобедимой и всё более непохожей на других — необратимо. Случайный старт решает, что кому «идёт»: Крыса с доминантой Липкое — прирождённая Липучка.

**Сверх 100** ген продолжает расти — Мутации уходят за ×2, крыса становится монстром. Это и есть межсессионная цель: не лимит, а вектор.

## 5. Примеры

- Новая крыса «Шмакодявка»: ДНК {Жирное 38, Заразное 27, Живое 22, остальные 2–6}. Выпила `{Косточка, Тряпка в мазуте, Шаурма}` = {Жирное 3, Едкое 1, Заразное 1} → **Жирная мышь Ступени 3** сразу (сила ×0.88 при гене 38), ДНК: Жирное 68, Едкое 12, Заразное 37. Толстая, медленная, 9 ячеек.
- Та же тройка вылита на карту: **Масляный гололёд 3** + **Кислотный дождь 1** + **Эпидемия 1** → Люди падают пачками, лужи кислоты, Дезинсектор на 60 %, гарантирован редкий Жирный Ингредиент. Стая идёт за Печенью.
- `{Петарда, Петарда, Сердце}` = {Шумное 2, Живое 1} → **Визгунья 2** (радиус 5). Если пить крысе с геном Шумное 8 — радиус 5 × 0.58 ≈ 3; крысе с геном 60 — 5 × 1.1 = 5.5.

## Хвосты (в туман / 013)

- Ограничение «одно Зелье — одна доминанта» может быть скучным: вариант — вторичное Свойство даёт «оттенок» (Кислотная пасть + Шумное = укус пугает). После 009.
- Сброс Мутации (Инкубатор в Норе) — пользователь хотел «без лимита»; оставить как дорогую постройку 013 или не делать.
- Пить на Вылазке — отложено ранее.
