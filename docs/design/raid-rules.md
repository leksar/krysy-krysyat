# Правила одной Вылазки (v1)

Решено в тикете 006 (2026-10-20). Числа — стартовые, крутятся по ощущениям после прототипов. Термины — по [CONTEXT.md](../../CONTEXT.md).

## Старт

- Все Крысы появляются вместе у **входной дыры**. Вход Выходом не является.
- Таймера нет. Уходить заставляют **Переполох** и **конечные карманы**.

## Переполох

Общая для карты шкала 0–100 %, **видна всем**. Растёт:
- медленно от времени;
- от каждой паники Человека;
- резко от убийства Человека; убийство Ребёнка — скачок.

Пороги: 30 % — Голуби прилетают чаще; 60 % — приходит **Кот**; 85 % — второй Дворник и **Стая** голубей; 100 % — выживать практически невозможно. Переполох не падает.

## Крыса

- Управление: джойстик + **Прыжок** + **Укус** + **Действие** (контекстно: пометить / поднять напарника / выход / съесть).
- Движение без Мутаций: бег и прыжок. Лазание, wall-jump, рывок и т.п. — Мутации.
- HP. Урон: топот Прохожего, метла Дворника, тапок Бабки, клюв Голубя, Кот. **Падение урона не наносит.**
- Лечение — только съесть Еду из карманов (тратится).
- HP = 0 → **лежит** 30 с, ползти не может. Напарник рядом держит Действие 3 с → подняла с частью HP. Не подняли за 30 с → умерла, карманы **высыпаются** на землю, напарники могут подобрать.

## Карманы

- Линейка из **6 ячеек** (растёт апгрейдами Норы). Предмет занимает 1–3 ячейки подряд, укладывается автоматически; руками — только выбросить.
- Размеры: Еда 1, Мусор 1, Выделения 1, Перо 1, Тушка голубя 2, Орган Человека 3.
- Полные карманы — естественный сигнал уходить.

## Люди (типажи на Дворе)

| Типаж | Поведение | Уязвим одной крысе? |
|---|---|---|
| Прохожий | ходит по маршруту; увидел крысу — паника, роняет Еду, бежит; зажатый — топчет | нет |
| Дворник | гоняется за крысами с метлой, основной урон | нет |
| Бабка | медленная, кидает тапок издалека | нет |
| Ребёнок | бегает, кричит (скачок Переполоха), слабый | **да** |
| Пьяный / Спящий | лежит на лавке, не реагирует | **да** |

- Здорового взрослого Человека одна крыса не загрызёт — он затопчет. **Стая** (≥3 укуса от разных крыс за 3 с) валит.
- Живой Человек роняет **Выделения** (Заражённый — редкие). Убитый даёт **Орган** (Заражённый — уникальный).

## Метка и Заражение

1. Крыса **пьёт** из источника воды на карте (лужа, кран) → «мочевой пузырь» полон (одна Метка).
2. Рядом с **Едой Человека** (на столе, в сумке, на лавке) жмёт Действие → **Меченая еда**.
3. Человек, который её съел, становится **Заражён**.

Стадии, по 30 с каждая:
- **Заражён** — внешне почти здоров; при контакте с другими Людьми заражает их с низким шансом.
- **Болеет** — медленнее, раз в 15 с роняет редкие Выделения.
- **Ослаб** — можно добить одной крысой; Орган уникальный.

## Голуби

| Вид | Поведение |
|---|---|
| Воришка | пикирует, крадёт 1 предмет из карманов, садится неподалёку — можно догнать и отбить |
| Драчун | клюёт, небольшой урон |
| Стая | прилетает на 85 % Переполоха, много сразу |

Убитый Голубь оставляет **Перо** (Мусор) всегда и **Тушку** (мелкий Орган) с шансом 25 %.

## Выходы на Дворе

| Выход | Условие | Время |
|---|---|---|
| Щель в заборе | всегда открыта, дальний край карты | 5 с |
| Люк канализации | на карте ≥2 Заражённых Людей | 5 с |
| Водосток | только без предметов размером 3 (Органы не пролазят) | 1 с |

Пока крыса ждёт у Выхода, её можно бить — Голуби и Дворник мешают.

## Конец Вылазки

- Вышедшая Крыса **вынесла**: её добыча зачтена сразу, дальше она зритель (камера за живыми).
- Вылазка заканчивается, когда все живые вышли или все лежат/мертвы.
- Провал бьёт только по тем, кто остался: полная потеря собранного.

## Между Крысами

Friendly fire выключен, воровства у напарников нет. «Крысятник» (крысы крысят друг у друга) — возможный поздний режим или Модификатор, в туман.
