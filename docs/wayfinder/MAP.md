# Карта: Крысы крысят

<!-- wayfinder:map -->

## Пункт назначения

Играбельная онлайн-версия «Крысы крысят», задеплоенная: клиент на GitHub Pages, сервер на Hetzner (`89-167-106-105.sslip.io`). 2–6 Крыс с телефонов под Discord-войс проходят Вылазку на карте «Двор» (платформер, реалтайм), собирают Ингредиенты, уходят через Выход, в Норе варят Зелья, льют их на карту (Модификаторы) и пьют (Мутации, ДНК). Прогресс Стаи и Крыс сохраняется между сессиями.

## Заметки

- **Исполнение входит в карту**: пользователь хочет играть, а не читать спеку. Тикеты доводят до задеплоенной игры.
- Словарь: [CONTEXT.md](../../CONTEXT.md). Каждая сессия читает его и держит в актуальном состоянии (skill `domain-modeling`).
- Общение с пользователем — по-русски, коротко, вопросы нумерованными раундами (skill `grilling`).
- Игра приватная («для личного архива»): без модерации, матчмейкинга, публичного релиза. Вход в комнату по коду, аккаунт = ник + секретный код.
- Hetzner VPS: там уже крутятся 3–4 чужих приложения. **Ничего чужого не трогать**, порты и прокси — только добавлять.
- Техстек не выбран намеренно: его определяют исследования 001–003. Единственные фиксы: web (PWA, Android-браузер), клиент — статика на GitHub Pages, серверу нужен `wss://`.
- Решения из грилинга при чартинге (уже зафиксированы, не тикеты): реалтайм-платформер с видом сбоку, камера у каждого своя, джойстик + кнопки; поймали → лежишь, напарник поднимает; провал = полная потеря собранного; таймера у Вылазки нет; на Вылазку ничего не берут; Мутаций без лимита («мышь жирная»); ДНК случайна при создании и сдвигается каждым Зельем; Органы — с убитого Человека, Выделения — с живого; Алхимия = Свойства + именные Рецепты; карты на старте: Двор, Кухня, Крыша; пиксель-арт из скачанных ассетов, стиль не важен.

## Ещё не определено

- **Давление без таймера**: Вылазка не закрывается по времени — что заставляет уходить, а не фармить бесконечно (нарастание Голубей, кот, дворник, усталость)? Станет тикетом после «Правила одной Вылазки».
- **Что значит «жирная мышь»**: Мутации без лимита — визуальное разрастание, минусы, стоимость? Зависит от модели ДНК.
- **Шалости** (выблевать шерсть в коляску): побочные действия ради веселья и бонуса — список, триггеры, награды.
- **Формат карт и редактор**: тайлмапы (Tiled?), размер уровня, как делать Кухню и Крышу после Двора.
- **Условные Выходы**: какие условия (заражено N, только с Органом, только одна крыса) — после правил Вылазки.
- **Звук и музыка**.
- **Зелья на Вылазке** (брать с собой, пить/кидать) — пользователь отложил; вернуться после первой играбельной версии.
- **Именные Рецепты**: первые 3–5, как открываются.
- **Discord**: логин через Discord и/или Discord Activity вместо вкладки браузера.
- **Вайпы/сезоны**: сбрасывать ли прогресс когда-нибудь.

## Вне охвата

- Публичный релиз, матчмейкинг, модерация, монетизация — игра для своей компании.
- Нативный Android APK / Play Store — только web/PWA.
- Больше 6 Крыс в одной Вылазке.
- Общий экран (split-screen) — у каждого своя камера, решено при чартинге.
