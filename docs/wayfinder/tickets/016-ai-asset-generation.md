## Вопрос

Пользователь предложил генерировать фоны и ассеты через Codex CLI субагентом. Факт: Codex CLI на машине не установлен, и сам он изображения не делает — нужен ключ к модели генерации (OpenAI Images API или аналог). Что не покрыто бесплатными паками (тикет 002): сайд-скроллерный тайлсет Кухни, Выделения (все виды), кадр прыжка крысы, кадры паники Людей, параллакс-фоны Двора под 16 px. Задача: (1) пользователь даёт ключ через переменную окружения `OPENAI_API_KEY` (не в чат); (2) скрипт `tools/gen-assets/` с промптами на пиксель-арт в заданной палитре и размерах, пост-обработка (даунскейл до 16/32 px, квантование палитры, удаление фона); (3) сравнить с ручной дорисовкой — что быстрее. Выход: папка `assets/generated/` с результатами и вердикт «годится / дорисовывать руками».
