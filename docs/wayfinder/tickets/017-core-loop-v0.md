## Вопрос

Пользователь: «давай-ка уже игру — кор-луп с людьми и так далее, чтобы мы потестили разные карты». Край карты достигнут: решений хватает, дальше — исполнение. Собрать из прототипа 011 настоящую игру по [raid-rules.md](../../design/raid-rules.md): Люди (Прохожий, Дворник, Ребёнок, Пьяный), Голуби (Воришка, Драчун), Ингредиенты на карте и Карманы, HP / лежит / подъём, Переполох с порогами, три Выхода, конец Вылазки и итог; карты в текстовом формате — Двор, Кухня, Крыша; комнаты по коду. Без Метки/Заражения, Норы и Алхимии (следующие слои: 018, 009/013). Клиент — `apps/client` на корне Pages, сервер — тот же `apps/server`. Выход: играют вдвоём с телефонов на трёх картах, список замечаний → следующие тикеты.

## Резолюция

Построено и задеплоено 2026-10-20/21 (https://leksar.github.io/krysy-krysyat/). Итерации по замечаниям пользователя: большие карты → процедурные карты из сида с проверкой проходимости (packages/sim/src/gen.ts), боёвка с замахом/цифрами урона/станом/i-frames, крысы твёрдые друг для друга, голуби реже, спрайты вместо эмодзи (векторная крыса оставлена по просьбе), вертикальный инвентарь, список комнат, кнопка «Прервать Вылазку». Поверх кор-лупа добавлены Метка/Заражение (стадии, Гной, уникальные Органы, Люк от заражённых) и Нора (см. 013/014).
