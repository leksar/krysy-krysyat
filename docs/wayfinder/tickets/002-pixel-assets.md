## Вопрос

Где взять свободные (CC0 / CC-BY / OGA-BY) пиксель-арт ассеты для платформера: спрайт крысы с анимациями (бег, прыжок, укус, лежит), люди (ходьба, паника), голубь (полёт, атака), тайлсет городского двора/помойки, кухни, крыши, предметы-ингредиенты (мусор, еда, органы), UI (джойстик, кнопки, иконки). Единый размер (16 или 32 px) желательно, стиль неважен. Источники: itch.io, OpenGameArt, Kenney и др. Выход: таблица «что / ссылка / лицензия / размер / что докрашивать» и рекомендация одного согласованного набора.

## Резолюция

Проверены страницы ~35 ассетов на itch.io / OpenGameArt / Kenney, лицензии сняты с самих страниц. Рекомендованный набор на сетке 16 px: мир — Warped City (ansimuz, CC0, 16×16, параллакс, крыши); крыса — Animated Rat and Bat (Calciumtrice, CC-BY 3.0, дорисовать прыжок); люди — Urban Character Pack (CC0, вид сбоку, дорисовать панику); голубь — Animated Birds 32×32 (CC0) с перекрасом; еда — Foodpack + 16×16 food (CC0); мусор — BTL Trash & Junk (CC0); органы — Reactorcore Gibs (CC0); UI — Kenney Mobile Controls + Input Prompts Pixel 16 (CC0). Слабое место — кухня: свободного сайд-скроллерного кухонного тайлсета нет, дорисовывать поверх Bad Kitchen (CC0). Полная таблица: [docs/research/pixel-assets.md](../../research/pixel-assets.md).
