## Вопрос

Одна крыса, одна комната с платформами, виртуальный джойстик + прыжок + укус, без сети, на стеке из 003, открывается с телефона. Пользователь играет минуту и отвечает: приятно ли прыгать, нужен ли coyote time / jump buffer, где должны быть кнопки. Выход: параметры физики и раскладка управления, ссылка на прототип.

## Резолюция

Прототип: https://leksar.github.io/krysy-krysyat/proto/010/ (код — `prototypes/010-touch/`, PixiJS 8 + чистая TS-симуляция `src/sim.ts` с фиксированным шагом 60 Гц, AABB против тайлов). Пользователь поиграл с iPhone (через Telegram) и с Android.

- **Физика**: пресет «Чёткая» — скорость 95 px/с, прыжок 300 px/с при гравитации 850 (падение 1250, обрыв прыжка 2200), высота ≈3.3 тайла; coyote 80 мс, jump buffer 100 мс, прыжок по длине нажатия — всё включено. «Остальное ок».
- **Раскладка**: A — Прыг (92 px) справа внизу, Кус (64 px) левее и чуть выше. Левая половина экрана — джойстик.
- **Найдено на iPhone в Telegram**: свайп от левого края = жест «назад» встроенного браузера, Fullscreen API нет. Решение: мёртвая зона 48 px у левого края, джойстик по умолчанию на фиксированном месте (x=130) с пунктирной подложкой, подсказка «открой в Safari → На экран Домой» там, где `fullscreenEnabled` ложен. Полноценное решение — PWA в standalone-режиме (manifest, уже в плане клиента).
- Баг: дуга укуса не зеркалилась влево — исправлено.
- Вывод по стеку: Pixi + свой sim собрались за один присест, Phaser-запасной не понадобился; архитектура «sim без DOM» подтверждена.
