## Рекомендуемый согласованный набор (сетка 16 px, спрайты 32×32)

Критерии: минимум не-CC лицензий, одна сетка тайлов, вид сбоку, минимум докрашивания.

1. **Мир (Двор, Крыша)** — **Warped City** (ansimuz, CC0, 16×16): тайлы + параллакс + пропсы + машины + готовые демо под Phaser/Godot. Работа — перекрасить неон в серо-бурую палитру двора и собрать помойку из `trash-can-0` (CC0) и BTL Trash & Junk (CC0). Фон Крыши — Cyberpunk Street / City Skyline того же автора (CC0) с перекрасом.
2. **Кухня** — Bad Kitchen tileset (CC0) как основа + техника из Kitchen Assets (reakain, custom, фронтальные виды) или Bluerobin2 (CC-BY 3.0). Самая слабая часть: готового сайд-скроллерного кухонного тайлсета под свободной лицензией нет, 1–2 вечера дорисовки неизбежны.
3. **Крыса** — Animated Rat and Bat (Calciumtrice, CC-BY 3.0): idle/walk/attack/death покрывают бег, укус и «лежит»; дорисовать 2 кадра прыжка. Запасной вариант с готовым run — Dungeon Rat (Originum, кредит).
4. **Люди** — Urban Character Pack (CC0, вид сбоку, 31 персонаж с walk/jump/attack): готовые городские типажи; дорисовать паническую ходьбу и позу «заражён» (перекрас в зелёный).
5. **Голубь** — Animated Birds 32×32 (MoikMellah, CC0, полёт 5 к.) перекрасить в сизого; «сидит/ходит» — из Pigeon (OGA, CC-BY/OGA-BY, 32×32). Если допускаем custom-лицензию — Pigeon Pixel (kangjung, 32×32, walk/fly/eat) закрывает всё сразу, остаётся атака.
6. **Ингредиенты** — Foodpack (IrSilva, CC0) + отбор из 16×16 food (CC0); Мусор — BTL Trash & Junk (CC0); Органы — Reactorcore Gibs (CC0) с перекрасом; Выделения — 2–3 своих иконки.
7. **UI** — Kenney Mobile Controls (CC0) для джойстика и кнопок + Input Prompts Pixel 16 (CC0) для иконок действий + UI Pack Pixel Adventure (CC0) для панелей Норы.

Лицензии набора: всё CC0, кроме крысы Calciumtrice (CC-BY 3.0) и голубя с OGA (CC-BY/OGA-BY) — две строки атрибуции в титрах. Если брать kangjung/reakain — добавляются два custom-условия «не перераспространять исходники»; для клиента на публичном GitHub Pages это значит: сырые паки в репозиторий не класть, только нарезанные атласы.
